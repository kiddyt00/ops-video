## 架构决策记录

### 为什么用 OSS 而不是本地存储？
- 云端 API 返回 URL 有效期仅 24 小时
- 多节点部署时文件不一致
- 前端直连 OSS 比后端代理快
- 成本极低（0.12 元/GB/月）

### 为什么分镜级 i2v 拼接而不是尾帧链？
- 尾帧链误差累积，6 次后角色可能变形
- 分镜级拼接 + 角色卡兜底更稳定
- 场景内连续用尾帧链，场景间硬切
- 混合方案：同 scene 用 extend()，不同 scene 用 generate()

### 为什么 Project = 短剧，Task = 章节？
- 短剧商业模式：前 3 集免费，后面按集解锁
- 每集独立发布（抖音/B站单集 1-3 分钟）
- 角色卡在 Project 级别共享，所有章节一致
- 迭代灵活：某集不满意重做那集就行
