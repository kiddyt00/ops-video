> AI 漫剧/短剧自动生成平台 | 49.235.108.61:8081

## 一、快速开始

### 1.1 登录

访问 `http://49.235.108.61:8081`，使用邮箱和密码登录。

首次使用需先注册账号。

### 1.2 创作一部漫剧

两种方式：

**方式 A：灵感一键创作（推荐）**

首页顶部输入框输入创意主题，点击"开始创作"：
```
例如：废柴少年林凡在悬崖边捡到一本星辰剑诀，逆天改命
```

系统会自动：
1. 创建项目
2. 走完"灵感"阶段生成初步创意
3. 跳转到项目详情页

**方式 B：新建项目**

点击右上角"新建项目"，填写名称和描述，手动进入项目后按 Tab 顺序操作。

## 二、项目详情页

进入项目后，顶部有 4 个 Tab：

```
故事 → 角色卡 → 章节 → 工作流
```

### 2.1 故事 Tab

**StoryWizard（故事向导）** — 6 步完成故事设定：

| 步骤 | 内容 | 说明 |
|------|------|------|
| ① 灵感 | 输入故事灵感 | 一句话或一段描述 |
| ② 类型 | 选择故事类型 + 基调 + 篇幅 | 修仙/玄幻/都市等 |
| ③ 世界观 | 选择力量体系 + 补充设定 | 修仙境界/魔法体系等 |
| ④ 主角 | 选择主角模板 + 补充描述 | 废柴/天才/重生等 |
| ⑤ 金手指 | 主角的特殊能力 | 系统/神器/传承等 |
| ⑥ 关系线 | 感情线和重要关系 | 单女主/后宫/无CP等 |

填完后点击"确认设定，AI 生成故事"，系统调用 LLM 生成完整故事大纲。

**生成结果包含：**
- 一句话梗概 (logline)
- 故事梗概 (synopsis)
- 世界观设定 (worldbuilding)
- 角色列表 (characters)
- 主题 (themes)
- 情节点 (plot_points)
- 书名建议 (title_suggestions)
- 目标读者 (target_audience)
- 风格标签 (style_tags)
- 预估字数 (word_count_estimate)
- 金手指详情 (golden_finger_detail)
- 力量体系 (power_system)
- 世界地图 (world_map_hints)
- 楔子预览 (prologue_preview)

生成后可在编辑器中直接修改任意字段，点击"保存"持久化。

**知识库注入**

故事生成时会自动注入内置知识库，包括：
- 中文姓名生成字典（姓氏 + 男女名用字 + 取名规则）
- 中文地名字典（20个前缀 + 15个后缀 + 命名规则）
- 朝代设定模板（10个时代模板）
- 修仙世界观设定指南（境界/宗门/灵石）
- 科幻世界观设定指南（科技等级/星际政治）
- 经典叙事结构（英雄之旅/三幕式等7种）

### 2.2 角色卡 Tab

管理角色外观和设定，用于后续图片生成时保持角色一致性。

每个角色卡包含：
- 角色名
- 角色描述（外貌、性格、服饰）
- 三视图/参考图

### 2.3 章节 Tab

显示故事的章节大纲列表。每章显示：
- 缩略图
- 章号 + 标题
- 状态（待开始/生成中/已完成/失败）
- 更新时间

点击章节进入该章节的工作流页面。

### 2.4 工作流 Tab

核心生成管线，包含 8 个阶段：

```
灵感 → 故事 → 章节大纲 → 剧本 → 分镜 → 生图 → 配音 → 成片
```

每个阶段可点击展开，查看制品和参数面板。

**操作按钮：**
- **开始生成** — 点击后弹出 GenerationPanel 浮动面板，AI 边生成边流式显示（打字机效果）
- **推进下一阶段** — 当前阶段完成后，推进到下一阶段
- **全部生成** — 一键跑完所有 8 个阶段

**GenerationPanel 面板功能：**
- 实时显示 AI 生成内容（打字机效果）
- 暂停/继续生成
- 停止生成
- 重新生成
- 可在暂停时输入反馈指令调整生成方向

## 三、角色关系与状态追踪

系统自动追踪角色的状态变化，防止跨章节的情节矛盾。

**追踪维度：**
- 生死状态 (alive/dead/injured/missing)
- 当前位置 (location)
- 所属势力 (faction)
- 角色关系 (mentor_of/rival_of/lover_of 等)

**前情提要注入：**

在生成章节大纲时，系统自动查询所有角色的最新状态和关系，组装为"前情提要"注入到 LLM 生成上下文：

```
前情提要（请保持情节连贯性）：
- 张三: status=alive, location=青云城, faction=青云宗
- 李四: status=dead（已于第3章死亡，不可复活）
- 王五: status=alive, location=B城

角色关系：
- 张三是王五的师父
- 李四是张三的仇人（已死亡）
- 王五效忠于青云宗
```

这样 AI 生成后续章节时不会出现"已死亡的角色复活"或"角色瞬间跨越遥远距离"这类矛盾。

**自动记忆提取：**

每次剧本/分镜生成后，系统自动调用轻量 LLM 分析文本，提取角色状态变化并更新数据库。

## 四、系统管理

### 4.1 AI 模型配置

路径：`/models`

配置 LLM 和图片生成模型的 API Key、Base URL 等。数据库驱动，不需要改环境变量。

### 4.2 用户管理

路径：`/users`

管理员可查看和管理用户，包括：
- 修改角色（用户/管理员）
- 禁用/启用账号

**注意：禁用/修改角色等操作有确认弹窗，误操作可取消。**

### 4.3 知识库管理

路径：`/api/v1/knowledge`

6 个内置知识库：
- 中文姓名库 (chinese-names)
- 地名库 (chinese-place-names)
- 朝代模板 (chinese-dynasties)
- 修仙世界观 (xianxia-world-rules)
- 科幻世界观 (scifi-world-rules)
- 叙事结构 (story-structures)

可新增/编辑/删除自定义知识库。

## 五、常见问题

### Q: 为什么生成结果等了很久？
LLM 生成需要时间，通常 30-120 秒。流式模式会在生成过程中实时显示内容。

### Q: 生成的内容不满意怎么办？
可以点击"重新生成"多次尝试。也可以在 GenerationPanel 暂停后输入反馈指令调整生成方向。

### Q: 数据会丢失吗？
项目数据存储在 PostgreSQL 数据库中。系统迁移或重启后数据不会丢失。

### Q: 如何确保多章节情节连贯性？
系统内置角色状态追踪功能，每次生成新章节时自动注入前情提要，防止情节矛盾。
