📋 6步完整流程

✅ 1 灵感

输入一句话或一段描述

→ inspiration

🔵 2 类型/基调

东方玄幻 · 热血 · 黑暗 · 轻松

→ genre + tone

⚪ 3 世界观

时代·力量体系·地域·势力

→ worldbuilding hints

⚪ 4 主角设定

姓名·身份·性格·背景

→ protagonist template

⚪ 5 金手指

传承·系统·血脉·重生·无

→ golden_finger

⚪ 6 关系线

单女主·后宫·无女主·宿敌

→ relationship

📦 所有选择汇总 → 拼入 LLM Prompt

灵感少年林凡偶得星辰剑诀
类型东方玄幻 · 热血激昂
时代上古修仙纪元
主角林凡 / 杂役 / 坚韧
金手指上古传承（星辰剑诀）
关系线单女主 + 师徒 + 宿敌
